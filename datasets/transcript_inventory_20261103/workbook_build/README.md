# Workbook build provenance

The workbook is authored with the managed `@oai/artifact-tool` runtime. `build_workbook.mjs` reads the adjacent published JSON files and exports the seven-tab Excel workbook; `add_native_links.py` adds standard Excel hyperlink relationships and explicit native table AutoFilter ranges without changing cell content. `validate_outputs.py` performs read-only checks using openpyxl, including exact forward/reverse link checks, filter-range checks and comparison with the prior workbook at commit `cb95abf07ba089c06676b4ce6f318347fbd760d6`.

These scripts preserve the execution used for this deliverable. They are not a standalone software package. The builder accepts its input/output directory as its first argument and writes preview images and `native_links.json` to `/tmp/jep-transcripts-8a7e64850a04`; create that working directory before running. The managed artifact-tool dependency must be available to Node. The native-link helper accepts the workbook and link-manifest paths as two arguments.

`assemble_outputs.py`, `finish_report.py` and `validate_outputs.py` retain the original research-workspace layout. The assembler depends on the local review checkpoints and original input inventory; the validator expects the earlier workbook under `upload/`. Those working caches and private source text are not distributed here. The published JSON files are the assembled data used by the workbook builder, so rebuilding the workbook does not require publishing source transcript text.

The crawler correction has its own independently replayable reduced fixtures and commands in [pagination_fix](../pagination_fix/README.md). The final [workbook validation](../workbook_validation.json) records preserved source links and summaries, recalculated counts, and the exact workbook checksum.

The ten-review tieout preserves the 93 source rows and 93 English summaries. Only the previously verified VV-057 alternate-upload fields and exact duplicate-metric prose for VV-008/VV-010 may differ from the prior source tab. `apply_tieout_decisions.py` records the bounded manual research decisions, including explicit date conflicts. The accepted reverse-disposition ledger prevents a new unreviewed upload from becoming a missing-transcript assertion automatically.
