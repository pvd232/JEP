## Optional bridges

- Mikhail Bilenko, Sugato Basu and Raymond J. Mooney. 2004. *Integrating Constraints and Metric Learning in Semi-Supervised Clustering*. ICML. Read for the historical connection between supervised distances and clustering constraints. [Proceedings PDF](https://icml.cc/Conferences/2004/proceedings/papers/119.pdf).
- Xinyue Liu and colleagues. 2025. *Conditional Semantic Textual Similarity via Conditional Contrastive Learning*. COLING. Read its loss equations before designing a new conditional ranking objective. [Proceedings and complete author list](https://aclanthology.org/2025.coling-main.306/).
- Gaifan Zhang, Yi Zhou and Danushka Bollegala. 2025. *Annotating Training Data for Conditional Semantic Textual Similarity Measurement using Large Language Models*. arXiv:2509.14399, v1. Read for the annotation lineage used by CASE. [Primary manuscript](https://arxiv.org/html/2509.14399v1).
