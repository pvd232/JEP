# Native evidence design: final fixed diagnostic recipe

This describes reviewed implementation and development choices, not a representative quality result. The original fixed diagnostic 48 and seven criteria remain independent. No further exposed prompt iterations follow the final Know candidate.

| Contract | Go | Know | Limitation |
| --- | --- | --- | --- |
| Typed NER | Zero-shot; exact Food leaf gets fixed definition/example | Original zero-shot | Food does not relabel Fruit/Vegetable |
| Color/generic condition-derived RE | Existing fixed RE example | Same | Family call permission is not correctness |
| Spatial | Full 21-predicate palette + Beside example | Same palette + all-constructor illustration | Cue is not binding/entailment proof |
| Action/motion/context activity | Actor/full-clause RE | Same + second complete retrieval example | Coarser than resolved EE |
| Composite scope | Exact declared entity/relation stages | Same | Context cannot imply unstated states/goals |
| Aggregate counts | Unsupported/zero calls | Unsupported/zero calls | Failed attempts remain archived |

The full fixed spatial palette preserves To/Toward, Over/Above, Into/Inside and OutOf/Outside. It is never narrowed by a caption preposition. The qualifier lives on the emitted edge and arguments are entity/place mentions. Full-source constructor-matching cue spans permit fronted syntax; attachment/entailment remain explicitly unvalidated. Attire in or an unrelated matching cue cannot certify the requested location. No parser invents/repairs a predicate.

Every EE-shaped direct/context activity becomes ActionDescription consistently. The quoted verbal clause retains stated objects, complements, negation and modality. Actor-to-clause association remains a model claim requiring validation; no complete actor/theme/place frame is asserted. A man's throw assigned to a dog remains wrong despite valid Python/exact spans. Supported partial clauses are reported as partial, not complete familiar-case success.

Go generation inputs remain unchanged from the first task-contract recipe; Know's four NER/two Color development strings also remain unchanged. The final Know spatial illustration covers every class with fixed independent assertions. Its action demonstration preserves the original gardener example and adds one archivist/scroll/cabinet/gallery example contrasting a bare verb with its full object/origin/locative phrase. No target dog/stick/leaves example, per-case source selector or prompt grid is introduced. These are explicitly development-selected system/task-contract choices, not isolated formatting effects.

The final Know spatial input 2511 + 512 reserve fits 4096. Pinned golaxy/KnowCoder-7B-IE revision `90ba076763dfb2e9efefd84a0e599f15ae533597` config and actual author vLLM setup support 4096. Other Know branches retain 2048; Go 16384. No original capture/budget is changed, source truncated or semantic inventory shrunk. Actual runtime/checkpoint/tokenizer/precision/resources remain separately sealed.

All imported Python and JSON assets enter implementation_identity; requests bind exact plans, stages, profiles, demonstrations, prompts and token budgets. Common graphs/exports preserve quote offsets, binding ambiguity and coarse-representation limits. Parse validity is not support. The offline CLI rederives parsed records from raw/source, preserves failures and leaves model-execution verification to the outer harness.

Original zero-shot, generic EE, fixed-family one-shot, task-contract and symbolic-count attempts remain immutable. CountEvidence quotes are not entities, presence, coreference links or interpreted totals. Its failed relevance/coverage does not repair counting, and it is not silently promoted into the positive diagnostic recipe. The fixed diagnostic must retain unsupported/failure rows and must not grant a full score merely for quoting source text.

The first diagnostic 48 included seven intentionally empty sources per model. The provider accepted those strings, but the core rejected them before neural generation. The original failures, provider and protocol remain preserved. A separate mechanical amendment changes only passage validation in the renderer and normalizer: empty/whitespace strings are allowed verbatim, nonstrings remain invalid, and fabricated nonempty spans still fail grounding. It changes no semantic recipe, instruction, example, ontology, class, budget or forced-output behavior; all 18 public nonempty prompt strings remain identical.

The [empty-input core](../training_outputs/csts_native_empty_input_v1_20261028.tar.gz) and [integration receipt](../training_outputs/csts_native_empty_input_integration_20261028.json) bind the two-guard repair. Recovery is a separate origin, `mechanical_empty_input_first_neural_generation_recovery_v1`, with all 14 first neural generations returning literal empty lists and passing replay in the [recovery receipt](../training_outputs/csts_native_empty_input_first_generation_recovery_20261028.json). It is not a semantic prompt iteration or a qualification result.

The reviewed amended core has 113 tests; three earlier repository whitespace regressions remain. The integrated 185-test suite and four separate public-entrypoint tests pass. Negative specificity and held-out quality are empirical gates, not consequences of code approval.
