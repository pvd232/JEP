Evidence attention: plan and derivations

Tranche 6: evidence supervision on the condition-dependent similarity readout

Decision and motivation

Run this bounded follow-up after the reviewed reference-correction tranche if its remaining overnight allowance permits completion. Fit two small attention heads over the same frozen selected Qwen + LoRA token states. One learns from similarity ratings. The other receives an additional loss that directs its attention toward previously accepted, copied teacher evidence. Reuse the archived Qwen comparator; perform zero native-baseline fitting or reproduction. Keep training seed 7.

The previous FLAN experiment found aligned evidence → ratings test Spearman 0.606654, with ratings → ratings 0.516796 and shuffled evidence → ratings 0.537700. The Qwen evidence-pretraining experiment found evidence → ratings 0.783645, with ratings → ratings 0.788505; the paired difference interval was [−0.013408, +0.003454]. Those observations motivate testing whether evidence supervision helps when it directly controls the token aggregation used for similarity. They supply no measured result for the present architecture.

The implementation already generated condition-specific copied evidence spans, with a separate teacher check. FLAN learned those answer tokens through its decoder while similarity pooled passage-token states. Qwen learned answer-token prediction after the embedding prefix and used the prefix's EOD representation for similarity. The new head makes the supervised probabilities themselves the pooling weights used by the similarity calculation. Both the existing frozen encoder and the information available at prediction time remain explicit.

This is a new readout architecture inspired by the evidence-localization idea. IPED's Level Predictor supplies a related architectural motivation: fused candidate-level/block states query its evidence features. Its reported relation-class probability vector is a classifier output. A free-text condition query and evidence-supervised token pooling are the construction defined here. Exact IPED model replication is outside this experiment.

Forward calculation

All vectors in the equations below are columns. For a passage-condition input, let n≥1n\ge1 be its number of selected passage-token positions and let m≥1m\ge1 be its number of selected condition-token positions. Let d=4096d=4096, r=128r=128, and p=512p=512 be the backbone width, query/key width, and final embedding width. Let hi∈Rdh_i\in\mathbb R^d be the frozen final hidden state at passage position ii, and let gj∈Rdg_j\in\mathbb R^d be the frozen final hidden state at condition position jj. Define

g=1m∑j=1mgj. g=\frac1m\sum_{j=1}^{m}g_j.

The condition positions precede the passage in Qwen's causal input. Their hidden states contain the instruction and condition prefix. Each selected passage state can incorporate the preceding condition and passage prefix through the frozen transformer. An earlier passage token has no access to later passage tokens. Qwen's pretrained retrieval readout uses the final token; this new aggregation tests whether supervision can make these earlier contextual states useful for similarity.

For any x∈Rdx\in\mathbb R^d, define the non-affine layer-normalization operation used by the attention keys and query:

μ(x)=1d∑a=1dxa,v(x)=1d∑a=1d(xa−μ(x))2,LN⁡(x)=x−μ(x)1dv(x)+10−5. \mu(x)=\frac1d\sum_{a=1}^{d}x_a, \qquad v(x)=\frac1d\sum_{a=1}^{d}(x_a-\mu(x))^2, \qquad \operatorname{LN}(x)=\frac{x-\mu(x)\mathbf1_d}{\sqrt{v(x)+10^{-5}}}.

Here aa indexes vector coordinates and 1d\mathbf1_d is the length-dd all-ones column. Learn bias-free matrices WQ,WK∈Rr×dW_Q,W_K\in\mathbb R^{r\times d} and WO∈Rp×dW_O\in\mathbb R^{p\times d}. Define the query qq, each key kik_i, each logit ℓi\ell_i, each attention weight αi\alpha_i, and the pooled value uu by

q=WQLN⁡(g),ki=WKLN⁡(hi),ℓi=ki⊤qr, q=W_Q\operatorname{LN}(g), \qquad k_i=W_K\operatorname{LN}(h_i), \qquad \ell_i=\frac{k_i^\top q}{\sqrt r}, αi=exp⁡(ℓi)∑a=1nexp⁡(ℓa),u=∑i=1nαihi. \alpha_i=\frac{\exp(\ell_i)}{\sum_{a=1}^{n}\exp(\ell_a)}, \qquad u=\sum_{i=1}^{n}\alpha_i h_i.

Padding logits receive negative infinity before softmax; padding weights are zero. Every input must have at least one valid passage position. Values remain the original frozen passage states. Define φ(x)=max⁡(x,0)+0.01min⁡(x,0)\varphi(x)=\max(x,0)+0.01\min(x,0), applied coordinate-wise. Define DD as inverted dropout with probability 0.15 during training and the identity during evaluation. The final passage vector is

w=D(φ(WOu)),z=w∥w∥2. w=D\bigl(\varphi(W_Ou)\bigr), \qquad z=\frac{w}{\lVert w\rVert_2}.

Reject nonfinite features and vectors with pre-normalization length at most 10−810^{-8}. Run the head and reductions in float32, with enclosing native-worker autocast disabled. Preserve float64 when explicitly checking derivatives with a double-precision head. The backbone forward uses the declared BF16 path and remains frozen in evaluation mode.

Evidence targets and losses

For each accepted training answer, require exactly one exact literal occurrence of its text inside the original passage. Build E⊆{1,…,n}E\subseteq\{1,\ldots,n\} from passage-token offsets having positive character overlap with that occurrence. If the accepted answer is present only after canonical normalization, occurs repeatedly, or produces an empty token set, record the missing unambiguous alignment and supply no span target for that occurrence. Preserve its rating comparisons in both arms. This avoids assigning evidence to the wrong entity when the same copied words recur.

For an aligned occurrence, define the fixed token target distribution t∈Rnt\in\mathbb R^n by

ti=1[i∈E]∣E∣. t_i=\frac{\mathbf1[i\in E]}{|E|}.

Here ∣E∣|E| is the number of selected evidence tokens and 1[P]\mathbf1[P] equals one when proposition PP holds and zero otherwise. This distribution is uniform over the copied span's token positions. It is a supervision target; it is unrelated to a teacher vocabulary-probability distribution.

Let BB be the actual number of comparisons in a training batch. For comparison bb, let zb1,zb2z_{b1},z_{b2} be its two unit embeddings, let yb∈[0,1]y_b\in[0,1] be its released rating rescaled through (rating−1)/4(\text{rating}-1)/4, and let sb=zb1⊤zb2s_b=z_{b1}^\top z_{b2}. The rating objective is

Lrating=1B∑b=1B(sb−yb)2. L_{\mathrm{rating}}=\frac1B\sum_{b=1}^{B}(s_b-y_b)^2.

Let AA be the set of the batch's individual passage occurrences having aligned evidence. An occurrence can recur through pair sampling. For occurrence j∈Aj\in A, let njn_j be its passage-token count and let tji,αjit_{ji},\alpha_{ji} be its target and predicted weight at position ii. Define

Lspan={−1∣A∣∑j∈A∑i=1njtjilog⁡αji,∣A∣>0,0,∣A∣=0. L_{\mathrm{span}}= \begin{cases} -\dfrac1{|A|}\displaystyle\sum_{j\in A}\sum_{i=1}^{n_j}t_{ji}\log\alpha_{ji},&|A|>0,\\ 0,&|A|=0. \end{cases}

Compute masked log probabilities before the target product, setting masked log probabilities to zero to avoid a zero-times-negative-infinity operation. The empty-target case returns a differentiable finite zero. Targets have unit mass for aligned occurrences and zero mass for unsupervised occurrences.

Gradient connection to the actual readout

For one supervised occurrence, the span derivative with respect to its valid logit is

∂Lspan∂ℓji=αji−tji∣A∣. \frac{\partial L_{\mathrm{span}}}{\partial\ell_{ji}}= \frac{\alpha_{ji}-t_{ji}}{|A|}.

In the evidence arm, multiply this derivative by 0.1 before combining it with the rating derivative. For the rating derivative, let zˉb1=∂Lrating/∂zb1\bar z_{b1}=\partial L_{\mathrm{rating}}/\partial z_{b1}; then zˉb1=2(sb−yb)zb2/B\bar z_{b1}=2(s_b-y_b)z_{b2}/B, with the analogous expression for the other passage. Through normalization,

wˉ=(Ip−zz⊤)zˉ∥w∥2. \bar w=\frac{(I_p-zz^\top)\bar z}{\lVert w\rVert_2}.

Here IpI_p is the pp-dimensional identity matrix and a bar denotes the derivative of the scalar objective with respect to that variable. After differentiating dropout, LeakyReLU and WOW_O, let uˉ∈Rd\bar u\in\mathbb R^d be the resulting derivative at the pooled value. Its attention-logit contribution is

ℓˉi=αi(hi−u)⊤uˉ. \bar\ell_i=\alpha_i(h_i-u)^\top\bar u.

The learned query and keys therefore receive rating supervision through the same weights that receive span supervision. For combined logit derivatives ℓˉi\bar\ell_i, the attention projections receive

qˉ=1r∑i=1nℓˉiki,kˉi=ℓˉirq, \bar q=\frac1{\sqrt r}\sum_{i=1}^{n}\bar\ell_i k_i, \qquad \bar k_i=\frac{\bar\ell_i}{\sqrt r}q, ∇WQL=qˉLN⁡(g)⊤,∇WKL=∑i=1nkˉiLN⁡(hi)⊤. \nabla_{W_Q}L=\bar q\operatorname{LN}(g)^\top, \qquad \nabla_{W_K}L=\sum_{i=1}^{n}\bar k_i\operatorname{LN}(h_i)^\top.

Sum these contributions across passage occurrences. The frozen Qwen and adapter parameters receive zero optimizer updates. Autograd supplies the implemented derivatives; numerical tests check the query, key, output projection, attention simplex, masked CE, padding, exact joins and restored-score behavior.
