# Tranche 8: checked propositions and answer-input LoRA

Authorized 26 October 2026. Execute the agreed source-first answer audit, compare generated propositions with cached spans under the same frozen scorer, then adapt the selected Qwen encoder when the answer-fidelity screen passes. No frozen-score improvement is required before adaptation. Reuse saved native predictions; do not rerun a baseline or fit another native control head.

## Fixed answer policy

Generate one answer independently from one passage and condition. A broad entity question includes every relevant referent and preserves their roles when needed; an explicitly role-qualified question restricts that role. Singleton entity conditions default to entity type. Preserve requested values, counts, negation, relations and qualifications. Permit direct lexical normalization and elementary counting; do not invent a precise age or breed, exact counts from bare plurals, room type, purpose, intent, or absence from nonmention. Retain partial information such as an unspecified plural when the exact number is unavailable.

Each record has `id`, `status` (`answered`, `not_specified`, `ambiguous`), `target`, `attribute`, `answer`, and `evidence` (a list of exact source spans). A generated answer may paraphrase and combine multiple supporting spans. Limit it to 60 words. Missing and ambiguous records have an empty answer and evidence list. Source containment validates quoted evidence separately from semantic fidelity. Embed only the answer under the original condition. Missing, ambiguous or rejected outputs fall back to the original passage and condition; never embed a common unknown token.

Use the existing authenticated `gpt-6.1-sol` CLI alias with requested reasoning effort `high`, fresh ephemeral sessions and a tools-forbidden prompt. Record the alias, provider defaults, prompts, schema, source and response hashes, usage, raw events and failed attempts. Reject tool activity. The CLI exposes no finer immutable provider snapshot. Requests contain only `id`, `passage`, `condition`; source-group metadata is external and used to allow at most one item from each original group per request. Keep training and validation requests separate. No companion passage, pair rating, prediction, pair ID or group ID enters a generation prompt.

## Audit before scoring

Sample 60 validation source groups uniformly without replacement (seed 61027), then one comparison per group (pair-choice seed 61028 plus group index). This produces 120 independent passage-condition records. Preserve the sample manifest separately. Two independent model auditors derive source-only references before seeing generated answers; each auditor sees at most one passage from any sampled source group. They receive no ratings, companion passages, old answers or model scores. Known regressions are inspected separately and do not enter the random-sample quality rate.

Compare generated decisions against the source and stated policy: correct target/property, all requested values and referents, counts, polarity/relations, sufficient evidence, unsupported inference and correct abstention. An omitted answer on an answerable case counts as a failure. Resolve reference/generator disagreements from source evidence, not similarity labels. The prospective screen requires at least 114/120 fully faithful decisions and zero accepted severe unsupported assertions. This is independent model-assisted development inspection, not human expert validation or a population-accuracy guarantee.

If the first prompt misses the screen, permit one documented policy/prompt revision based only on this development audit and a fresh 30-source-group/60-record check, disjoint from the original sample. Require at least 57/60 faithful decisions and zero accepted severe unsupported assertions. Preserve both attempts. A second failure stops full generation and training, and reports the limiting error classes.

After fidelity passes, compare old and new representations on exactly the sampled pairs and original two-pair inference layout. Retain every pair, report answer coverage, Spearman, MSE and condition ordering; small-sample ranking is descriptive. Saved Qwen scores remain the original-passage comparator. The quality gate is semantic fidelity, not a frozen cosine win.
