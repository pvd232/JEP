Status: proposed experiment with implementation supplied for review. This delivery contains the specification, derivations, experiment code, focused tests, and an MOA review record. The experiment has not started. The completed Tranche 4 remains the latest measurement.

Question and working hypotheses

Which reference construction produces the most useful conditional similarity representation after the scoring head learns that representation?

The four candidates use a generic representation of the same passage, an average conditioning shift across real training passages, removal along that average direction, and a CASE-style condition-target representation. Each candidate trains one small head. The existing sealed Qwen + LoRA predictions supply the baseline: validation Spearman 0.7825746597420997, test Spearman 0.7885050017660868. Baseline scoring, numerical reproduction, and native-head fitting are excluded from this experiment.

The working hypothesis is that references estimated from matched real text can isolate useful condition-dependent variation. A learned scalar can adjust correction strength, and a shared head architecture can adapt each representation to similarity ratings. These are project hypotheses. Their tests are predictive accuracy, conditional ordering, the false-positive/recall operating point, and the affected comparison rows.

Tranche 4 found 0.78257 validation Spearman and a 9.69% false-positive rate at 90.11% recall for native Qwen + LoRA. Its full-strength empty-passage condition subtraction produced 0.69657/0.68956 Spearman and 21.86%/20.00% false-positive rates. The global mean pairwise cosine decreased during condition subtraction. This motivates evaluating the retained task information directly.

δm,c=h(xm,c)−h(xm,c0),bc=1M∑m=1Mδm,c∈Rd. \delta_{m,c}=h(x_m,c)-h(x_m,c_0), \qquad b_c=\frac1M\sum_{m=1}^{M}\delta_{m,c} \in\mathbb R^d.

Bank selection defines the distribution summarized by bcb_c. The symbol denotes an empirical mean; its interpretation as a removable shared component is an experimental hypothesis.

To describe sampling variability, suppose an idealized collection of independent, identically distributed paired shifts has covariance Σδ∈Rd×d\Sigma_\delta\in\mathbb R^{d\times d}. Then

Cov⁡(bc)=ΣδM. \operatorname{Cov}(b_c)=\frac{\Sigma_\delta}{M}.

Let Σc\Sigma_c and Σ0\Sigma_0 be the covariance matrices of conditioned and generic readouts, and C=Cov⁡(h(x,c),h(x,c0))C=\operatorname{Cov}(h(x,c),h(x,c_0)) their cross-covariance. Pairing gives

Σδ=Σc+Σ0−C−C⊤. \Sigma_\delta=\Sigma_c+\Sigma_0-C-C^\top.

Positive shared variation can therefore cancel in the paired difference. This variance calculation is theoretical. The supplied code caches the mean bank direction. Individual-shift storage and leave-one-bank-member-out stability measurements remain future diagnostics motivated by this calculation. Distinct source groups reduce direct caption reuse; statistical independence remains a modeling assumption in the calculation.

10. Why raw reference lengths remain relevant

For a nonzero passage readout hh and reference bb, let z=h/∥h∥2z=h/\lVert h\rVert_2 and u=b/∥b∥2u=b/\lVert b\rVert_2. Then

unit⁡(h−αb)=unit⁡(z−α∥b∥2∥h∥2u). \operatorname{unit}(h-\alpha b) =\operatorname{unit}\left(z-\alpha\frac{\lVert b\rVert_2}{\lVert h\rVert_2}u\right).

11. Validation ranking and condition ordering

Let aja_j and bjb_j be the average ranks of prediction y^j\widehat y_j and target yjy_j, including average ranks for ties. These rank symbols are scalars, separate from the bank reference bcb_c. Define their means aˉ=N−1∑jaj\bar a=N^{-1}\sum_j a_j and bˉ=N−1∑jbj\bar b=N^{-1}\sum_j b_j. Spearman correlation is

ρ=∑j=1N(aj−aˉ)(bj−bˉ)∑j(aj−aˉ)2∑j(bj−bˉ)2. \rho= \frac{\sum_{j=1}^{N}(a_j-\bar a)(b_j-\bar b)} {\sqrt{\sum_j(a_j-\bar a)^2}\sqrt{\sum_j(b_j-\bar b)^2}}.

Constant predictions or targets make the denominator zero and require an explicitly undefined correlation result.

For condition ordering, let Q\mathcal Q contain unordered pairs of comparison indices (j,l)(j,l) with the same passage-pair identity, different condition strings, and different targets. Define

djl=y^j−y^l,tjl=yj−yl,K=∣Q∣. d_{jl}=\widehat y_j-\widehat y_l, \qquad t_{jl}=y_j-y_l, \qquad K=|\mathcal Q|.

Acond=1K∑(j,l)∈Q(1[djltjl>0 ∧ ∣djl∣≥εo]+121[∣djl∣<εo]). A_{\mathrm{cond}}=\frac1K \sum_{(j,l)\in\mathcal Q} \left( \mathbf1[d_{jl}t_{jl}>0\ \land\ |d_{jl}|\ge\varepsilon_o] +\frac12\mathbf1[|d_{jl}|<\varepsilon_o] \right).

12. Inclusive recall cutoffs and confusion counts

Define validation positives P={j:Rj≥4}\mathcal P=\{j:R_j\ge4\}, negatives N={j:Rj≤2}\mathcal N=\{j:R_j\le2\}, and desired recall q=0.9q=0.9. Let n+=∣P∣n_+=|\mathcal P|, and sort positive predictions in descending order as u(1)≥⋯≥u(n+)u_{(1)}\ge\cdots\ge u_{(n_+)}. The largest observed threshold meeting the recall requirement is

τ=u(⌈qn+⌉). \tau=u_{(\lceil qn_+\rceil)}.

The ceiling ⌈v⌉\lceil v\rceil is the smallest integer greater than or equal to scalar vv. Predict positive when y^j≥τ\widehat y_j\ge\tau, including ties. Define

TP=∑j∈P1[y^j≥τ],FN=∑j∈P1[y^j<τ],FP=∑j∈N1[y^j≥τ],TN=∑j∈N1[y^j<τ]. \begin{aligned} \mathrm{TP}&=\sum_{j\in\mathcal P}\mathbf1[\widehat y_j\ge\tau],& \mathrm{FN}&=\sum_{j\in\mathcal P}\mathbf1[\widehat y_j<\tau],\\ \mathrm{FP}&=\sum_{j\in\mathcal N}\mathbf1[\widehat y_j\ge\tau],& \mathrm{TN}&=\sum_{j\in\mathcal N}\mathbf1[\widehat y_j<\tau]. \end{aligned}

These symbols mean true positives, false negatives, false positives, and true negatives. The rates are

recall⁡=TPTP+FN,FPR⁡=FPFP+TN,FNR⁡=FNTP+FN. \operatorname{recall}=\frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FN}}, \qquad \operatorname{FPR}=\frac{\mathrm{FP}}{\mathrm{FP}+\mathrm{TN}}, \qquad \operatorname{FNR}=\frac{\mathrm{FN}}{\mathrm{TP}+\mathrm{FN}}.

Each selected arm has its own validation threshold. Carry it into the existing test partition unchanged and report realized test recall. Rating-3 rows remain in regression and ranking metrics. Any zero rate denominator is explicitly undefined.

13. Paired source-group uncertainty

Let GG be the number of connected source groups in a scored cohort and Ig\mathcal I_g the comparison indices belonging to group g∈{1,…,G}g\in\{1,\ldots,G\}. Bootstrap draw b∈{1,…,Bboot}b\in\{1,\ldots,B_{\mathrm{boot}}\} samples GG group indices independently with replacement, then concatenates all rows from the sampled groups. Here Bboot=2000B_{\mathrm{boot}}=2000, using the fixed bootstrap seed in the plan.

The implemented bootstrap metrics are Spearman, MSE, false-positive rate, and recall. For one of these metrics TT and candidate arm aa, compute

Δb(a)=Tb(a)−Tb(N). \Delta_b^{(a)}=T_b^{(a)}-T_b^{(N)}.

The superscript NN denotes the sole existing native comparator, using its sealed predictions. Every system uses identical sampled groups within a draw, and classification thresholds remain fixed at their validation values. The 2.5th and 97.5th percentiles of valid Δb(a)\Delta_b^{(a)} values form the paired percentile interval. Record invalid draws and require at least 95% valid draws for each metric. These intervals describe cohort-sampling uncertainty for the fitted checkpoints and existing comparator.

Conditional ordering is a point estimate and a point-difference selection guard in this implementation. Its bootstrap interval remains a future extension.

For validation selection, let ρa,Aa,Fa\rho_a,A_a,F_a be candidate aa's Spearman correlation, conditional-ordering accuracy, and false-positive rate at its validation recall cutoff. Let ρN,AN,FN\rho_N,A_N,F_N be the corresponding quantities for the existing native predictions. Eligibility requires all three inequalities:

ρa−ρN≥0.005,Aa−AN≥−0.01,Fa−FN≤0.01. \rho_a-\rho_N\ge0.005, \qquad A_a-A_N\ge-0.01, \qquad F_a-F_N\le0.01.

Select the eligible candidate with greatest validation Spearman, using the plan's fixed tie order. Existing-test transfer applies these guards and also requires candidate recall to decline by at most 0.01 relative to native recall, using the frozen validation thresholds. The rate and accuracy tolerances are absolute fractions; 0.01 is one percentage point.
